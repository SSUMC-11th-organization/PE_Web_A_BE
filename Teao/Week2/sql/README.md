# Week 2 - SQL로 데이터 다루기

원본 작업 이슈: https://github.com/SSUMC-11th-organization/PE_Web_A_FE/issues/16

## 실행 순서

MySQL 8.0 이상에서 Workbench로 각 파일을 열어 순서대로 실행합니다.

1. `01_schema.sql`: `library_week1` 데이터베이스와 8개 테이블 생성
2. `02_seed.sql`: 공통 더미 데이터 입력
3. `03_queries.sql`: 공통 미션 1~3 실행

`03_queries.sql` 마지막 확장 쿼리는 자신의 1주차 ERD(`member`, `member_mission`, `mission`, `store`, `region`)용입니다. 공통 DB에는 이 테이블들이 없으므로 파일 전체를 한 번에 실행하지 말고, 공통 미션 1~3만 선택해 실행합니다. 확장 쿼리는 해당 ERD로 만든 별도 DB를 선택한 뒤 실행합니다.

## 미션

- 문학 카테고리의 대여 가능한 도서를 최신순으로 최대 10개 조회
- 사용자 1의 미반납 도서를 반납 예정일순으로 조회
- 책 1의 태그 목록과 사용자 1의 좋아요 여부 조회
- 확장: 회원 1의 완료 미션을 최근 완료순으로 조회

기준 테이블, JOIN 이유, WHERE 조건, 정렬 기준은 각 쿼리 위 주석에 작성했습니다.

## 검증 범위

SQL 파일과 실행 안내를 제출합니다. 실행 결과 캡처는 포함되어 있지 않습니다. 확장 쿼리를 실행하려면 별도 1주차 ERD 스키마와 데이터가 필요합니다.
